# BCH Ecosystem

Curated directory of Bitcoin Cash (BCH) projects by Nordic Crypto. Live: https://bch.nordiccrypto.no

GitHub Pages serves this repository from the root of `main` (legacy build). `CNAME` and `.nojekyll` stay in place so the custom domain is unchanged.

Edit `data.js` to add entries. There is no site build. `npm test` checks that every entry has the required fields and an HTTPS URL, and that card titles render as the project name.

Sister directories: https://nexa.nordiccrypto.no and https://nordiccrypto.no
